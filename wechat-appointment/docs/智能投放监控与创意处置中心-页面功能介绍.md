# 智能投放监控与创意处置中心｜页面功能介绍

版本：产品方案 v1.0（2026-10-23）
定位：推广运营模块下的独立页面；本文为功能与验收说明，不代表功能已经上线。

## 1. 页面目标

把当前分散的账户健康、素材分析、在投创意和创建记录汇入一个可执行的监控工作台。运营人员能按账户与营销单元查看近期消耗和目标转化成本，及时发现异常，核对原因，然后在权限允许的范围内执行暂停、恢复、删除、替换和定时开启。自动策略先以提醒和待审核建议为主；通过真实账户验证后，才逐项开放受控自动处置。

建议入口：**推广运营 → 智能投放监控**。现有“账户健康”“素材分析”“新建创意”“批量新建”页面保留，继续承担深入分析与创意创建功能；新页面负责连续监控、异常归因和快捷处置。

## 2. 当前项目基础与需新增能力

| 能力 | 当前基础 | 本页面需新增 |
|---|---|---|
| 账户健康 | 有周期汇总、健康分、异常原因和建议 | 自动刷新、账户异常事件、变化趋势与工单式处置 |
| 素材分析 | 有账户/业务单元分析、消费、曝光、点击、转化和部分目标转化成本 | 创意与素材关联、持续衰退识别、替代素材推荐 |
| 数据同步 | 腾讯/巨量日级同步；北京时间 10:00、14:00、22:00 调度 | 腾讯账户及创意级十分钟监控采集；与原日级账表分开 |
| 创意查询和创建 | 腾讯创意列表查询、单账户及多账户新建、创建后二次核验 | 在投创意状态同步、更新/暂停/删除能力核验、处置编排 |
| 权限 | 已有推广账户数据范围、素材查看和创意创建授权 | 监控、手动处置、自动策略、删除、定时操作分别授权 |

现有账户健康的固定内部基线（例如表单成本 210 元）仅适合作为历史参考，不能直接用于所有账户、项目和投放目标的自动删停。新页面须按账户、营销单元、转化目标和生效日期维护目标成本与阈值。

## 3. 页面布局

### 3.1 顶部范围与状态栏

- 账户选择：腾讯广告账户多选，支持业务单元、项目、负责人、账户状态筛选；仅返回当前成员可见的账户。
- 时间窗口：实时监控（最近 10/30/60 分钟）、今日、昨日、近 3/7/15/30 天；与上一等长窗口及昨日同时段比较。
- 同步状态：每账户最近请求时间、平台数据截止时间、接口返回时间、下一次计划时间、数据延迟、失败原因。
- 平台范围：首期只对已验证的腾讯广告账户开放自动创意操作。巨量账户可在能力对齐后加入；界面不得把腾讯操作按钮显示给不支持的平台。
- 总开关：监控开关与自动执行开关分离。自动执行默认关闭，并展示当前作用范围和维护人。

### 3.2 概览卡片

展示已监控账户数、正常/关注/严重异常账户数、当前在投创意数、待核验创意数、今日消费、今日目标转化数、今日实际目标转化成本、超目标成本创意数、同步失败数、待处理预警数。所有指标可点击下钻，空值必须显示“暂无数据”，不能当作 0。

### 3.3 账户健康区

每个账户展示账户名、户号、业务单元、余额/预算（仅在平台可返回时）、授权状态、投放状态、最近同步、今日与昨日同期消费、曝光、点击、转化、目标成本、实际成本、健康等级和异常因素。支持进入该账户的在投创意清单。

异常包括：授权失效、无数据、数据延迟、账户/营销单元停投、消耗突然归零、消耗突增、连续有点击无转化、实际成本超过目标、有效线索率下降。必须区分“投放异常”“统计回传延迟”和“样本不足”。

### 3.4 在投创意监控表

一行一条腾讯侧创意，至少展示：账户、营销单元、广告/创意 ID、创意名称、创意类型、平台配置状态、平台实际状态、审核状态、创建时间、视频/标题/落地页摘要、今日和近 1 小时消费、曝光、点击、目标转化、实际目标成本、设置的目标成本、偏差、最近 3/7 天趋势、最近同步时间、异常标签、操作记录。

支持账户、营销单元、状态、风险等级、异常类型、素材、投放目标、负责人、消耗区间、成本区间和时间范围筛选；支持列自定义、排序、保存视图与分页。素材级统计无法准确归因到单条创意时，展示归因口径和“不可用于自动处置”标识。

### 3.5 异常事件中心

预警按“账户 → 营销单元 → 创意/素材”组织；每条事件包含触发规则、目标值、实测值、样本量、数据窗口、平台数据时间、证据、建议动作、责任人、首次/最近触发时间、确认人和处理结果。同一根因合并持续告警，恢复正常时关闭；支持静默、升级、指派和备注。提醒可优先使用后台站内通知，外部通知通道以项目已有授权能力和新增配置为准。

## 4. 数据采集与统计口径

### 4.1 十分钟调度

- 每隔十分钟为每个**启用监控且有平台授权**的账户建立一次同步任务，按账户错峰执行，避免整点接口风暴。
- 每次采集账户、营销单元、创意状态及平台允许的统计维度；创意列表分页拉全。单账户失败不阻塞其他账户。
- 使用项目现有腾讯 API 客户端、账户凭证和 User Token 机制；不另建 Token 系统。读取、状态更新和删除等接口需要分别验证当前应用权限。
- 通过持久化任务、分布式租约和幂等键防止多实例重复采集；超时重试、分页续传、限流退避、补采和同步告警必须可追踪。
- **十分钟是采集频率，不等于腾讯平台每十分钟都提供已结算的十分钟报表。** 若接口只返回日累计或有回传延迟，页面明确显示“采集于”和“平台数据截至”，十分钟变化值只能由两个已验证的累计快照计算。不得将日级数据伪装为实时数据。

### 4.2 指标定义

核心指标：消费、曝光、点击、点击率、目标转化数、转化率、实际目标转化成本、目标成本、超标幅度。实际目标转化成本优先使用腾讯平台返回且口径匹配的字段；不可用时可用同口径消费/目标转化数计算，标注“系统计算”。当目标转化数为 0 时成本显示“—”，不能显示 0 元。

平台转化、项目挂号/留资、有效线索是不同口径，默认分开展示。只有确认归因链路与时间窗口一致后才做联合诊断。费用统一转为元，保存原始单位和转换规则；跨日按 Asia/Shanghai 处理，保留晚到数据的回补和快照修订记录。历史日级报表继续沿用原系统归档规则，不得被十分钟快照覆盖。

### 4.3 目标成本设置

目标成本采用“账户默认 → 营销单元 → 创意例外”三级优先级，并记录转化目标、适用时间、生效日期、币种/单位、设置人和变更历史。若平台本身提供目标出价/成本字段，可读取为参考，但必须区分“平台投放目标成本”和“本系统告警阈值”。没有配置或口径不一致时，只提醒配置缺失，不触发自动操作。

## 5. 智能诊断与规则引擎

建议先用可解释的规则引擎，保留规则版本、输入快照和判定依据；“智能建议”只帮助排序和解释，不能绕过阈值与权限。

规则应支持账户/营销单元/创意适用范围、统计窗口、最低消费、最低曝光/点击/转化样本、目标成本倍率、连续触发次数、冷却期、每天最大执行次数和排除名单。示例：近 3 小时消费达到目标成本的 2 倍且目标转化为 0、平台数据新鲜、连续两个采集窗口满足条件时，发出高风险预警；是否自动暂停由该规则的授权与保护条件决定。

异常分类：消耗异常、成本异常、转化中断、素材疲劳、审核/状态异常、落地页或转化回传异常、数据缺失。素材复用多个创意时，先定位到具体创意和投放目标，不能仅因素材总体表现差就删除所有引用创意。

每次诊断须输出“为什么异常、数据证据、可能原因、建议动作、置信等级”。数据不足、平台统计延迟、转化回传故障、投放刚开启或刚修改过的学习期，默认只提醒，不自动删停。推荐替代创意时按相同账户、营销单元、创意类型、模板、素材授权和组件有效性预检。

## 6. 快捷操作与执行顺序

所有平台写操作均须在提交前重新查询目标创意与账户权限，提交后再次查询腾讯侧状态。操作结果分为“请求已受理、腾讯侧已确认、失败、结果不明”；仅确认后展示为完成。

| 操作 | 页面交互与规则 |
|---|---|
| 暂停创意 | 展示影响范围和当前状态，二次确认；调用经验证的腾讯创意状态接口。若腾讯只允许在广告/营销单元层暂停，必须展示真实影响范围，不得将更大范围操作伪装成暂停单条创意。 |
| 恢复创意 | 先确认账户、上级营销单元、审核状态和排期允许投放，再更新状态并查询确认。 |
| 删除创意 | 高风险独立权限、强确认；记录删除前快照、操作者和原因。删除可能不可恢复，默认不纳入自动策略。 |
| 删除并新建相同创意 | **先处理旧创意，再创建新创意。** 执行前保存旧创意完整配置与素材/组件快照，预检新建所需资产、模板、权限和配额，并展示可能出现的投放空窗。操作者确认后，先调用腾讯侧删除旧创意并回读确认旧创意已不在投或已删除；未确认时停止流程。随后使用快照创建新创意，保存新 ID，并查询确认账户、营销单元和关键组件。新创意还须经历平台审核，创建成功不等于审核通过或恢复投放。若新建失败，进入“旧创意已处理、新创意创建失败”的待人工恢复状态；仅在腾讯允许且回查确认的情况下提供恢复旧创意选项，不得擅自重复创建。 |
| 定时开启投放 | 设置北京时间日期、时间、目标范围及失效时间；到点重新校验权限、平台状态、账户/营销单元状态、审核、预算和素材。优先使用已核实的平台排期接口；若采用系统定时调用，明确它依赖服务正常运行并记录执行与核验结果。 |
| 批量操作 | 逐创意展示预检、预计影响和结果；单条失败不隐瞒整体部分成功。 |

“相同创意”指配置快照等价，不代表腾讯平台会保留旧创意的审核结果、学习数据、投放历史或原 ID。用户已反馈“先建新创意再删除旧创意”可能因重复度过高被腾讯拒审，因此替换流程必须按上述先旧后新的顺序执行；但先删除也不保证新创意通过重复度审核。页面须提示旧创意删除后可能无法恢复、新创意可能审核失败和投放中断，不能把两个平台请求描述为可原子回滚的交易。正式上线前以测试账户验证“删除回读 → 新建 → 审核状态查询”的真实行为。

## 7. 自动处置分级

1. **观察模式（默认）**：自动采集、诊断、提醒，所有操作由人执行。
2. **辅助模式**：系统生成带证据的暂停/恢复/替换建议，经有权限的成员确认后执行。
3. **受控自动模式**：仅允许已逐项验证的平台动作，例如在严格阈值下自动暂停或到点恢复；每条规则单独启用、限定账户和执行次数。删除和删除并重建默认始终需要人工确认。

自动调整预算、出价或投放状态前必须验证该动作的腾讯接口、账户权限和影响层级。首版不承诺“系统自行优化到目标成本”；可衡量目标是减少发现和处置异常的时间，并降低误操作。提供一键停用全部自动策略的熔断开关、规则灰度、执行冷却期和操作后观察期。

## 8. 权限、审计与安全

建议新增“监控查看、规则管理、手动暂停/恢复、定时操作、创意删除、替换创建、自动策略启停、结果导出”独立权限，合并到现有成员权限页面。复用推广账户数据范围及账户授权；操作人对目标账户和创意必须同时有数据范围与动作权限。超级管理员沿用项目现有判定方式；服务端强制校验，不能只靠前端隐藏按钮。

后台定时任务需保存发起人、授权规则及服务身份；成员权限撤销、账户授权失效或账户移出范围后停止后续执行。所有写操作保存操作前后平台状态、请求摘要、平台响应摘要、查询确认结果、操作者、触发规则和时间。Token 不进入前端或审计明文。批量删除、删除并重建提供预览和二次确认。

## 9. 关键数据对象

建议新增：监控账户配置、十分钟采集任务、平台状态快照、指标快照、成本目标配置、监控规则、异常事件、处置任务、处置步骤、定时动作及审计记录。所有对象使用稳定的账户、营销单元和创意平台 ID；快照保存数据来源、统计窗口、平台数据截止时间和版本。唯一键至少约束“账户 + 采集窗口 + 维度”和“目标创意 + 动作 + 业务幂等键”。

## 10. 交付阶段与验收

**阶段一：只读监控。** 接口能力盘点、十分钟采集、账户与创意列表、成本目标、数据新鲜度、异常事件与站内提醒。验收：两个真实账户连续采集，核对腾讯后台消费与转化口径，验证分页、延迟、失败补采和权限隔离。

**阶段二：人工快捷处置。** 实现已获腾讯接口授权的暂停、恢复、删除、替换和定时开启；每个动作都要有预检、确认、平台回读、审计与失败恢复。替换操作须验证旧创意先被腾讯确认处理，之后才发起新建，并覆盖“旧创意已删除但新建或审核失败”的人工恢复路径。验收：在测试账户执行，人工核对腾讯后台的创意状态、新创意 ID 和审核结果；旧功能回归正常。

**阶段三：受控自动策略。** 从提醒转为建议，再灰度放开低风险的自动暂停/定时恢复；删除和替换维持人工确认。验收：验证数据延迟、零转化小样本、账号无权、平台限流、任务重启、多实例并发、重复执行及熔断场景。

上线门槛：腾讯侧当前版本接口及目标账户授权已实测；十分钟数据口径可解释；真实平台状态回读通过；未达成这些条件的操作只能显示“待接入/不可用”，不得模拟成功。

## 11. 外部接口与能力核对清单

开发前逐项核实腾讯广告当前账号与 API 版本对“创意查询、状态更新、删除、创建、定时投放、报表维度及频率”的支持情况。官方 SDK 可作为端点线索，但生产行为以目标账户实际权限、接口响应和回读结果为准。尤其要核实：暂停对象究竟是创意、广告还是营销单元；创建新创意能否复用旧素材/组件；目标转化成本字段是否可按十分钟窗口获得。
