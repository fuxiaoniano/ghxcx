## 本轮补充：创意任务可靠性

- **P1，已修改，腾讯实测未完成**：单账户批量创意在获得腾讯创意 ID 后直接写入 `SUCCEEDED` 和 `verifiedAt`，未查询腾讯，可能错误显示已核验。现在按 ID 回查，并核对营销单元、规格、类型及组件；无结果或不一致保持 `UNKNOWN`。带 ID 查询时不再用同名其他创意代替。无 ID 的不确定请求即使超过五分钟仍不能仅凭查不到就自动重建。模拟测试覆盖无结果、同名不同 ID、匹配成功以及不确定请求避免重投。腾讯真实账户回读和兼容性尚未验证，平台返回字段缺失可能需要人工处理。

- **P1，未修复**：单账户任务的不确定请求按名称回查时可能存在同名或平台延迟，查不到不证明未创建。本轮移除了无结果后的自动重建，但完整的多候选歧义处理、人工核对流程和生产端验证仍待完成。
