# 口腔医院官方小程序设计系统

> 本文件是新增页面的视觉与交互基线。用户提供的 8 张参考图优先级高于通用模板；旧挂号页面不套用本规范，避免改变线上链路。

## 设计方向

- 产品定位：企业官方口腔医院小程序，强调可信、清晰、易预约。
- 视觉语言：医疗蓝、白色卡片、浅蓝灰背景、克制阴影、圆角分区。
- 信息架构：首页快速入口与推荐医生；医生、预约、套餐采用任务导向布局；个人中心采用分组菜单。
- 密度：中等偏紧，适配微信小程序常见 375px 宽度，不使用夸张大标题或大面积装饰动画。

## 颜色令牌

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 主色 | `#3478F6` | 导航激活、主要按钮、链接 |
| 主色深 | `#1557C0` | 强调标题、按压态 |
| 主色浅 | `#EAF3FF` | 图标底、选中背景 |
| 页面背景 | `#F5F8FC` | 页面底色 |
| 卡片背景 | `#FFFFFF` | 信息卡片 |
| 主文字 | `#172033` | 标题、关键信息 |
| 次文字 | `#5B667A` | 描述信息 |
| 弱文字 | `#8D98AA` | 辅助信息 |
| 边框 | `#E5EBF3` | 分隔线、输入框 |
| 成功/可预约 | `#16A77A` | 可预约状态；不替代主 CTA |
| 价格/警示 | `#F05A47` | 套餐价格、风险提示 |
| 错误 | `#D9363E` | 表单错误与破坏性操作 |

所有正文与背景对比度至少 4.5:1；不能只用颜色表达状态。

## 字体与排版

- 微信原生字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`。
- 页面标题 36rpx/600，区块标题 32rpx/600，正文 28rpx/400，辅助文字不小于 24rpx。
- 正文行高 1.5；医生擅长与详情正文允许多行，列表摘要最多 2–3 行并提供详情入口。

## 间距与形状

- 基础间距：8rpx；常用间距 16/24/32rpx。
- 页面左右安全边距：24–32rpx。
- 卡片圆角：16–24rpx；按钮圆角：12–999rpx，页面内保持一致。
- 阴影只用于浮层或重点卡片：`0 8rpx 24rpx rgba(42, 82, 140, 0.08)`。
- 所有触控区域至少 88rpx × 88rpx，相邻触控目标间距至少 16rpx。

## 关键组件

- 底部导航固定 5 项：`首页 / 医生介绍 / 预约挂号 / 推荐套餐 / 个人中心`，当前项使用主色和实心/加粗状态。
- 首页轮播预留固定比例，加载前保留高度，避免布局跳动。
- 医生卡：头像、姓名/职称、医院、擅长摘要、明确的“挂号”按钮；整卡进入详情，按钮直接预约。
- 双栏分类：左侧固定分类，右侧内容可滚动；选中项同时使用色块与字重区分。
- 表单：保留可见标签，不以 placeholder 代替；错误紧邻字段；提交中禁用重复点击并显示反馈。
- 套餐价格：销售价为主，原价为辅且划线；“购买人数”文案按申请/咨询业务表达，不暗示已支付。

## 动效与性能

- 仅使用 150–250ms 的颜色、透明度和轻微位移动效；尊重系统减少动态效果设置。
- 图片使用后台生成的合适尺寸，列表图懒加载并预留宽高；头像与封面提供失败占位。
- 禁止 emoji 充当功能图标，使用同一套本地图标资源。
- 禁止依赖 hover；所有关键操作必须有按压态、加载态、成功/失败反馈。

## 交付检查

- 375px 等效宽度无横向滚动，底部安全区内容无遮挡。
- 触控区域、颜色对比、空状态、加载态、错误态、图片失败态齐全。
- 医生详情 `doctorId` 深链和预约自动选中可回归。
- 旧挂号页面视觉、路由和提交行为不被新样式污染。
