## 字段一致性结论

- `doctor.departmentIds`：后台多选 -> DTO -> 关联表 -> 公开医生数据一致。
- `doctor.displayText`：后台编辑 -> 数据库 -> 医生列表展示一致。
- `schedule.date/timeSlot`：公开详情 -> 预约页预选 -> 预约写库一致。
- `category.name/icon/sort/status`：后台 -> 首页 API -> 首页科室模块一致。
- `originalPrice/salePrice`：后台 -> 套餐 API -> 小程序展示一致。
- 用户记录响应不含后台 `status/statusText`；后台预约响应仍保留管理字段。
- 上传响应返回素材记录和 HTTPS URL，后台各内容页面可重复选择。
