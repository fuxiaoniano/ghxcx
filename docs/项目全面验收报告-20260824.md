## 2. 项目现状

- 小程序：原生微信小程序、TypeScript、WXML、WXSS，17 个页面、5 个 tabBar 页面。
- 后端：NestJS、TypeScript、Prisma、MySQL 8、Redis 7、JWT、Swagger。
- 管理后台：Vue 3、Vite、TypeScript、Element Plus、Pinia、Axios。
- 部署：Docker Compose、Nginx、HTTPS，后端容器仅监听服务器本机 `127.0.0.1:3000`。
- 主要业务：旧挂号、医生预约、套餐咨询申请、用户中心、后台内容管理、手机号授权与审计、公众号/小程序通知。

关键业务链路：

1. 后台配置 -> 管理 API -> MySQL -> 小程序公开 API -> 小程序页面。
2. 小程序登录/手机号授权 -> 用户身份 -> 预约写库 -> 后台统一预约列表 -> 通知日志。
3. 后台查看完整手机号 -> 权限校验 -> AES 解密 -> 审计日志。
